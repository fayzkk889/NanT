# Contributing

Use Node.js 22+ and Python 3.12 for local source tools. Start with START-HERE.md. Run `npm test` and `npm run check` before proposing changes. Live acceptance checks must identify their source and distinguish real downloads/model runs from mocks and authored fixtures.

Keep public-source adapters, local transcription, frame capture, generation, verification and export modular. Do not silently replace missing source material with model knowledge. Code imported from a course must remain data and must never execute in the application. Keep cancellation, input-size limits and loopback-only serving intact.

Do not include `.env`, `.tools`, `.local-data`, recordings, captions, model weights, generated course books or private source bundles in source submissions. Preserve third-party attribution notices. Changes to this software are offered under its MIT license.
